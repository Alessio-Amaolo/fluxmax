Fluxmax is a small package for leveraging fmmax's differentiable RCWA implementation to compute near-field radiative heat transfer between bodies.

It provides a reference implementation of the Polder-Van Hove formula for planar bodies, as well as a general trace formula for patterned bodies. It can be used to perform inverse design of patterned surfaces for controlling radiative heat transfer.
